# KITABAK 📚
This is a project that aims to provide a platform for book lovers to share and discover and  books. The project is built using modern web technologies and follows best practices in software development.

## Stack
- "Frontend": React, TypeScript, TailwindCSS, Vite, Zustand, React Query, ReactRouter, React Hook Form, Zod, Axios, React Toastify, React Icons, React Markdown

- "Backend": Node.js, Express, TypeScript, Drizzle ORM, PostgreSQL, Zod, Dotenv  sentry, clerk, imagekit, cors, pg.
